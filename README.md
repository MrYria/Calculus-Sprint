# CalculusSprint

> High-speed mental calculus, derivatives, and mathematics trainer built with React & TypeScript.

## Tech-Stack
- **Frontend:** React, TypeScript, Tailwind CSS
- **Math Rendering:** KaTeX
- **Build Tool:** Vite

# Project is actively under development.

## Getting Started 

```bash
# Clone the repository
git clone https://github.com/MrYria/calculus-sprint.git

# Install dependencies
npm install

# Run development server
npm run dev
